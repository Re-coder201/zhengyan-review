# still. 政治复习

一个无需构建工具的静态学习软件，适合部署到 GitHub Pages。

## 已有模块

- 阅读复习：三本独立入口——马原、毛中特、习近平新时代中国特色社会主义思想；依次进入章节、小节和独立知识点页，支持荧光笔、编辑正文、备注和收藏。
- 真题套卷：先选择马原或毛中特，再按年份进入一套独立试卷；每题下方显示依据背诵手册整理的参考答案，可评分和收藏。
- 我的收藏：知识点与题目分栏，点击展开可查看答案与掌握度。
- 智能复习：先选择“随机出题”或“收藏里出题”，再按知识点、真题或混合内容加权抽题。复习题在独立页面呈现，可定位回原知识点或原真题并高亮。
- 全局陪伴形象：人物趴在右下角，任何模块都可点击并获得动态加油提示。
- 设置：主题色、字号、本机记录与动态更新状态。

## 部署到 GitHub Pages

将本目录提交到 GitHub 仓库，在仓库 **Settings → Pages** 中选择从主分支根目录部署即可。打开页面后，点击“检查更新”会显示检查中，随后明确提示是否为最新版本。

## 内容说明

知识点目录与正文来自三份提供的背诵手册；真题按所给文件中的科目和年份整理。高频真题已额外建立手工题目—知识点交叉对应，便于从复习页准确跳转与定位。
